Comitê Burnout

Projeto em Python (Jupyter Notebook) que usa uma base de dados sobre burnout do Kaggle para prever o nível de burnout de uma pessoa (leve, médio ou alto) e calcular a acurácia do resultado.

O que o projeto faz
Carrega a base de dados com o pandas.
Trata e organiza os dados. (PREENCHER: o que você fez, por exemplo remover valores vazios, converter colunas, separar treino e teste)
Faz a predição do nível de burnout: leve, médio ou alto.
Calcula a acurácia para medir o quanto o modelo acerta.
